# M10 Kaizen evidence

Evidence for the my-10-kaizen operation (plan prepared 29 September 2026). Each phase `M10-00` to `M10-14` writes command transcripts, JSON reports, executor evidence files and reviewer verdicts into its own sub-folder. The running log is `../m10-kaizen-execution-2026-09-29.md`.

Rules for every sub-folder:

- Client material (for example regenerated `.docx` files under `srs-skills/projects/`) is never copied here; record only its path and SHA-256.
- No book extractions and no copied third-party text.
- A check that could not run is recorded as `NOT_ASSESSED` with a reason; it never counts as a pass.
- Evidence is added, not rewritten. Corrections are new dated entries.
