# AC-C02 routing versus execution

Run python -B evals/behavioural/ai_routes.py. The frozen synthetic queries are original project examples. Each carries a source for its intended owner and its split. BM25 and reciprocal rank come from the existing retrieval metric library. Eight requests represent seven distinct families; one is a near duplicate. A correct classifier route returned an incorrect fixture label. A code-review case returned its expected effect count. Six requests lack a measured result. The denominator for task success is the two assessed outputs.

All eight route expectations matched. Three abstentions cover ambiguity, an unrelated request and an empty permitted corpus. The ranked control X then Y gives reciprocal rank 0.5 for Y. A label-provenance gap found in independent review was repaired by citing the casebook or catalogue for every query. This is a deterministic local routing proxy with fixed synthetic outputs. The opt-in live behavioral suite remains unassessed.
